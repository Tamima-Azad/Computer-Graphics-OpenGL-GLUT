# Computer Graphics with OpenGL & GLUT

A collection of Computer Graphics lab exercises, drawing algorithms, 2D/3D visualizations, animations, and interactive games developed using **C++ and OpenGL/GLUT**.

This repository contains my practical coursework and projects for **Computer Graphics (CSE-4206)** at Bangladesh Army University of Engineering & Technology (BAUET).

## Technologies Used

- **Programming Language:** C++
- **Graphics Library:** OpenGL, GLUT
- **IDE:** Visual Studio Code
- **Compiler:** MinGW / GCC
- **Platform:** Windows

## How to Run

### Requirements

- C++ Compiler (MinGW/GCC)
- OpenGL
- GLUT Library
- Visual Studio Code or another compatible IDE

### Clone the Repository

```bash
git clone https://github.com/Tamima-Azad/Computer-Graphics-OpenGL-GLUT.git
```

### Open the Project

```bash
cd Computer-Graphics-OpenGL-GLUT
```

Navigate to the desired project folder.

### Compile and Run

For a typical single-file GLUT program on Windows:

```bash
g++ main.cpp -o main.exe -lglut32 -lopengl32 -lglu32
```

```bash
./main.exe
```

*Note: Compilation commands may vary depending on the project structure and GLUT setup.*
